# 本地模型：下载、分发与替换

## 两个模型各做什么

| 模型 | 用途 | 默认 GGUF 文件 | 向量维度 |
| --- | --- | --- | --- |
| BAAI/bge-m3 | 把记录、片段和问题转成向量，用于检索 | bge-m3-Q8_0.gguf | 1024 |
| BAAI/bge-reranker-base | 对检索候选重新评分、排序 | bge-reranker-base-Q8_0.gguf | 不适用 |

它们不负责聊天答案生成。文字抽取与回答使用另外配置的 LLM；图片理解使用可选 VLM。

## 开源时上传什么

提交源码、依赖锁文件、配置模板和本文；不把 GGUF 权重、llama.cpp 二进制、Python 环境、个人数据、`.env` 或 Key 放进 Git。本地工作目录中的模型与环境只是运行材料，都已被 `.gitignore` 排除。

开发者自行取得模型和与系统匹配的 llama.cpp 构建：

- BGE-M3 官方模型卡：https://huggingface.co/BAAI/bge-m3
- BGE reranker 官方模型卡：https://huggingface.co/BAAI/bge-reranker-base
- llama.cpp 官方发布：https://github.com/ggml-org/llama.cpp/releases
- 服务接口与启动参数：https://github.com/ggml-org/llama.cpp/tree/master/tools/server

官方模型卡提供原始权重；当前启动器需要 GGUF，原始 safetensors 不能直接重命名成 GGUF。选择由当前 llama.cpp 支持的转换方式或可信的 GGUF 发布，并核对模型来源、版本、量化、许可证和校验值。本项目没有随附可验证的第三方 GGUF 下载出处，因此不编造一键下载链接。

## 默认安装位置

```text
backend/models/bge-m3-Q8_0.gguf
backend/models/bge-reranker-base-Q8_0.gguf
backend/llama/llama-server.exe          # Windows，以及同次发布的依赖 DLL
backend/llama/llama-server              # Linux，或通过配置使用其他路径
```

## 能否换模型

可以扩展，当前不是任意模型即插即用。默认组合是已经适配的组合；换一台服务器不代表换模型。

1. 嵌入模型必须支持当前 llama.cpp 的嵌入服务，或由其他服务提供兼容的 `/v1/embeddings` JSON 响应。接口须按输入返回 `index` 和 `embedding`。
2. 重排模型必须支持 `/v1/rerank`，返回与候选对应的 `index`、`relevance_score`。聊天模型不能直接代替重排模型。`RERANK_ENGINE=off` 可关闭重排；`llm` 路径另有调用成本，不等于任意 GGUF 都能重排。
3. `.env` 中 `EMBEDDING_MODEL`、`RERANK_MODEL` 是标识；`EMBEDDING_MODEL_FILE`、`RERANK_MODEL_FILE` 是实际 GGUF 路径。仅改名称不会自动下载或加载另一份权重。
4. 启动器支持配置 `LLAMA_SERVER_BINARY`、`LLAMA_THREADS`、`LLAMA_EMBED_CONTEXT`、`LLAMA_EMBED_URL`、`LLAMA_RERANK_URL`。本机一键入口只负责启动本机回环地址的服务；远端兼容服务应独立部署，再手动启动后端。
5. 嵌入维度目前在 `backend/app/core/llm.py` 的 `_DIM_BY_MODEL` 中登记：bge-m3 为 1024，bge-small-zh-v1.5 为 512。新增模型要登记真实输出维度；如果还涉及特殊输入前缀、归一化或接口格式，需要调整客户端并验证检索效果。
6. 换嵌入模型后，即使维度相同，也必须重新计算原有数据的全部向量。停止应用并备份完整 data 目录（包括 secret.key），启动新嵌入服务，再在 backend 中运行 `python scripts/reembed.py --data-dir ./data`。完成后重启后端。不要让两个不同模型的向量混用。
7. 网页体验版更换嵌入模型，还必须重建虚构示例模板，并处理尚未到期的旧体验空间。停站后备份运行数据，等待旧体验结束，再以新模型生成新的 demo_seed，避免模板索引混用。

`LLAMA_EMBED_CONTEXT` 同时控制默认启动器的 context/batch/micro-batch；不同架构、硬件和 llama.cpp 版本还可能要求调整启动参数。换模型后的兼容性需要实际验证，不能只以“服务能启动”判定。
