# 开源命名与描述

> 采用名：**Whence · 来处**。一句话：把文字、照片和文件留在本地，用一句话找回生活的来龙去脉——每条回答都指回它来自的记录或原件。

## 一、名字

| 项 | 内容 |
| --- | --- |
| 英文名 | **Whence** |
| 读音 | /wɛns/ |
| 中文名 | **来处** |
| 品牌写法 | `Whence · 来处` |
| 品牌短句 | 每一段记忆，都有来处。 |
| 英文短句 | Every memory has a source. |

### 含义

- **Whence**：英文疑问副词，“从何处来、出自何处”。它天然是个溯源词——问一个结果从哪来，就是在问 whence。
- **来处**：中文里“来处”与“去处”相对，指一个人、一件事、一段记忆的出处。比“来源”更有温度，也比“起源”更日常。
- 两个词放在一起，正好对应产品的两个动作：记录当下，解释过去。

### 为什么是这个名字

1. **和产品内核同构**。这个项目最硬的差异不是“记得多”，而是“记得清”：每条回答都带出处、能回到原始记录和原件，同一件事的旧状态也能查（双时态）。`Whence` 就是这个承诺的英文单词。
2. **和现有文案同义**。前端原本就写着“找回生活的来龙去脉”，中文名“来处”让这句话更短、更像品牌。
3. **在 AI memory 赛道里是错位的**。Cairn、Loci、Pensieve、MemKeep、Keepsake、Engram、Hearth 等“记忆容器 / 存储”词已被大量占用（见第六节）；“来处”说的是记忆的出处与可信度，不是又一个存储词。
4. **双语互补**：英文名负责辨识度与可搜索，中文名负责温度与传播；侧栏 200px 宽度内放得下“Whence · 来处”。
5. **自带文案**：`每一段记忆，都有来处。` 一句即可表达产品哲学，README、启动页、社交简介都能复用。

### 风险与对策

- 英文偏古雅，部分读者可能误读成 “when”。对策：首次出现给读音与中文释义，中文名做主视觉。
- PyPI 上已有小工具包 `whence`，GitHub 有 `vicjohnson/Whence`（非记忆类）。对策：若发布到 PyPI，用 `whence-memory` 或 `get-whence`。
- 中文“来处”未检索到同名 App；上线前仍建议做一次商标检索（见第七节）。

## 二、描述文案（可直接复制）

### 一句话

**中文**：把文字、照片和文件留在本地，用一句话找回生活的来龙去脉——每条回答都指回它来自的记录或原件。

**English**: A local-first personal memory archive. Capture notes, photos and files, ask in plain language, and get answers that link back to the original records.

### GitHub 仓库 About（≤ 350 字符）

> 本地优先的个人记忆库，单用户自托管。记录文字、照片和文件，用自然语言找回，答案附出处、可回到原件；数据默认留在本机，敏感信息本地打码。

> Local-first personal memory, self-hosted. Keep notes, photos and files; ask in plain language and get answers with sources that open the original records. Hybrid search, provenance, sensitive data masked locally.

## 三、备选方案

| 名字 | 中文 | 含义 | 结论 |
| --- | --- | --- | --- |
| Quipu | 结绳 | 印加结绳记事 | 语义极贴（结绳即记录），但已有 scbrown/quipu、koi-quipu 等，读音对中文用户陌生。**备选一** |
| Endpaper | 环衬 | 书页与封面之间的衬纸 | 文艺，有“夹在生活里的纸”感；EndPaper 已是阅读记录 App。**备选二** |
| Daybook | 日簿 | 日记 / 流水账本 | 直白好懂；daybook-ai 等已用，偏“日程”不偏“记忆”。 |
| Hearth | 炉边 | 家与温暖的中心 | 情感好，但 AI memory 赛道已有 Hearth（身份记忆）。不建议。 |
| Memini | 我记得 | 拉丁语“我记得” | 贴切，但已有同名 MCP memory server。不建议。 |

Cairn / Loci / Pensieve / MemKeep / Keepsake / Engram 等首选词查名时均已发现同类项目（见第六节），故未列入。
